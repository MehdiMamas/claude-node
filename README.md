# claude-node

Turn a plain Linux box (Ubuntu Server, Raspberry Pi, a cloud VM, an old PC) into an always-on [Claude Code](https://docs.anthropic.com/en/docs/claude-code) node: Remote Control kept alive, a self-hosted CI runner, and memory limits so many sessions can share one machine. Raspberry Pi 4/5: see [docs/raspberry-pi.md](docs/raspberry-pi.md).

Status: planning. The plan is in the [issues](../../issues). Contributions welcome, see CONTRIBUTING.md. MIT licensed.
