# Contributing

Thanks for helping! Pick an open issue (or open one first for a new idea), then send a PR that links it.

- Keep the base OS stock: changes go into cloud-init, autoinstall, systemd units or scripts under `node/`.
- Test on at least one of: arm64 (Raspberry Pi, Oracle Ampere) or x86_64, and say which in the PR.
- Never commit secrets, tokens or personal hostnames.
